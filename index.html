Commandos Ubuntu

Meest voorkomende commandos Ubuntu van Marco

Tree

Geeft een bestandboom van de bestanden in de map die je op dit momment zit.

lS

Geeft een Lijst van de bestanden in de map die je op dit momment zit.

Pwd

Laat zien in welke bestanden je op dit momment zit.

cd

Hiermee ga je terug naar de begin map.

cd ..

Hiermee ga je 1 map terug.

cd/home

Hiermee ga je terug naar de home map.

cp

Met deze command kun je een bestand kopieren en plakken

mkir

Met deze command kun je een nieuwe map aanmaken.

rm

Hiermee kun je een bestand verwijderen.

mv

Bestand verplaatsen.

txt

Bestand aanmaken.

man

Handleiding van de commandos.

touch

Maakt een leeg nieuw bestand.

Nano

is comand line text editor.

cat

Laat de inhoud van een bestand zien.

less

Laat inhoud per pagina zien.

head

Laat bovenste regels van pagina zien.

tail

Laat onderste regels van bestand zien.
